# FN Traduction — Site web (version finale)

Site bilingue (Français / বাংলা) : traduction assermentée, interprétation, services administratifs, Formation, devis.
Logo et couleurs : vert canard + rouge du logo FN Traduction.

## Publier sur GitHub Pages
1. Dans votre dépôt GitHub, envoyez **le contenu** de ce dossier (index.html à la racine, avec css/, js/, fonts/, img/ à côté).
2. Settings → Pages → Branch `main` / `(root)` → Save.
3. Attendez 1 à 2 minutes, puis rechargez avec Ctrl+F5.
